# Upload these screenshots to App Store Connect

## Folders

| Folder | Size | Use in Connect |
|--------|------|----------------|
| `upload/6.5-inch/` | 1284 × 2778 | **iPhone 6.5" Display** (what Connect shows for you) |
| `upload/6.1-inch/` | 1170 × 2532 | **iPhone 6.1"** if that slot appears |
| `upload/6.7-inch/` | 1290 × 2796 | **iPhone 6.7"** if that slot appears |

Originals stay as `IMG_0001.PNG` … in this folder (`IMG_0001` = home pick stop; latest capture also kept as `IMG_0008.PNG`).

## Upload order (same in both folders)

1. `01-home-pick-stop.png` — Home, pick your stop  
2. `02-pick-stop-stations.png` — Station list  
3. `03-monitoring-transit.png` — Transit trip watching  
4. `04-wake-alert-settings.png` — Wake by stops sheet  
5. `05-map-destination.png` — Map pin destination  
6. `06-monitoring-map-pin.png` — Map-pin trip watching  

## In App Store Connect

1. Open DozeAlert → your iOS version → **Screenshots** → **iPhone**.  
2. For **iPhone 6.5" Display**, drag all six files from `upload/6.5-inch/` in order 01 → 06.  
3. If Connect also asks for **6.1"** or **6.7"**, use those folders the same way.  
4. Click **Save**.

Do not use Wear screenshots. Portrait only.
